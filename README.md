## Sobre mí

Estudiante de **Diseño y Desarrollo de Software en Tecsup** (4.º ciclo). Me gusta construir sistemas que resuelven problemas reales de negocio: inventarios, mesas de ayuda, comparadores de precios, paneles de administración.

- 💼 Ya desarrollé un **sitio web con panel de administración para una empresa**.
- 🚀 Fundé **NissiDev**, mi marca para hacer webs, sistemas y apps a medida para negocios.
- 🔭 Ahora construyo **Helpdesk Android**, una app de mesa de ayuda en Kotlin.
- 🎯 Busco **prácticas pre-profesionales** en desarrollo de software.
